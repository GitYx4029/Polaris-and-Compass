# Polaris and Compass · A股成交观察

[在线使用（GitHub Pages）](https://gityx4029.github.io/Polaris-and-Compass/)

展示上证、深证、沪深合计、科创板、沪深 ETF 和 510300 成交额，以及近 20 交易日累计、日均与资金温度；提供趋势图和历史 CSV。页面打开时北京时间 12:00、15:15 定点刷新，平时每 2 分钟更新；每日轮换一条有出处的投资观点，可导出观点库。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。运行 `npm run build` 检查生产构建。

## 数据与单位

- 数据来自腾讯行情上证指数 `sh000001`、深证成指 `sz399001` 的日线成交额，并用同一接口的即时报价字段核对近期日期及金额。GitHub Pages 静态版直接从浏览器读取腾讯行情脚本接口；原 Sites 版本先走服务端，失败时由浏览器直连。
- 日线原始金额为万元，统一换算为亿元计算；大额在页面转换为万亿元，CSV 统一保留亿元。这里只统计**成交额**，不是股数或基金份数。仅对两市都有数据的交易日计算合计，休市日不补值。20 日平均＝累计 ÷ 20；资金温度＝当日沪深合计 ÷ 20 日平均。
- 科创板按上交所股票成交概况的科创板栏目取成交金额（亿元）；沪深 ETF 首选东方财富 ETF 行情的全部分页（`f6` 成交额，元），检查总记录数、代码去重及同日时间戳再求和。东方财富不可用时，逐批检索腾讯行情沪市以 `0` 结尾的 5 开头代码，以及深市 158/159 全代码段，只累计报价分类为 `ETF` 且时间戳为同一交易日的证券，并检测每批是否完整返回。2026-09-24 的沪市部分再与上交所公布的沪市 ETF 成交额核对。510300 使用腾讯财经对应 ETF 日线。细分项属于上层市场，不能跨层相加。
- GitHub Actions 在北京时间工作日 12:10 和 15:25 获取细分项，核验后写入 `public/data/market-snapshot.json` 并部署页面；ETF 历史从采集成功之日累积。页面实时读取腾讯行情，也按相同频率读取已核实的细分数据快照。细分项缺失或日期不符时显示待核实。
- 这里是指数行情提供的沪深市场成交额口径，与交易所严格仅计 A 股的分类统计可能有细微差异。页面的区间和文字为观察参考，不是可验证的买卖信号。腾讯接口并非本站控制，访问限制或源字段变化可能造成暂时不可用。定时刷新在页面打开时运行；休市日保留最近交易日，并显示数据日期。

## GitHub Pages 发布

`main` 分支包含 GitHub Actions 工作流，抓取数据并执行 `npm run build` 后将 `out/` 发布到 Pages；仓库的 Pages 来源已设为 GitHub Actions。页面保持打开时定时读取行情，重新打开时立即抓取。GitHub Pages 在不同地区的连通性取决于当地网络，部署成功不代表中国大陆各运营商均稳定可达。

观点库保存在 `lib/investorQuotes.ts`，每条都附原始资料、具体位置和链接；页面的中文短句是依据原文归纳或意译，不是逐字引述。
