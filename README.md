# Polaris and Compass · 大A观测助手

[在线使用（GitHub Pages）](https://gityx4029.github.io/Polaris-and-Compass/)

展示上证、深证、沪深合计、科创板、沪深 ETF 和 510300 沪深300ETF华泰柏瑞成交额，以及近 20 交易日累计、日均与资金温度。两张趋势图均可用横向日期滑轨精确选择交易日；各数值与表格列均有单项历史 CSV 下载，另有完整历史 CSV。手机上的近期交易日为可展开卡片，可下载当日数据；三块解读参考在手机上左右滑动，整体放在页面末尾。参考区间的匹配状态标在相应指标旁，其他市场层级仅显示可比口径的前交易日变化；无同日数据或口径不一致时不标。Reference list 依次呈现指南针（日成交额）、北极星（20 日累计）、资金温度计及指标层级，并注明观察工具箱来自“袁莹投资思维”；这些观察阈值并非经验证的交易信号。页面打开时北京时间 12:00、15:15、15:55、16:55、17:55、18:55 定点刷新；每日轮换一条有出处的投资观点，每 5 天中 2 天选取复利、耐心、市场情绪等投资主题；可保存包含五项行情及数据阶段的 PNG 图片、复制含出处的文案或调用系统分享，也可导出完整观点库。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。运行 `npm run build` 检查生产构建。

## 数据与单位

- 数据来自腾讯行情上证指数 `sh000001`、深证成指 `sz399001` 的日线成交额，并用同一接口的即时报价字段核对近期日期及金额。GitHub Pages 静态版直接从浏览器读取腾讯行情脚本接口；Sites 版本先走服务端，失败时由浏览器直连。已核验快照与行情并行获取：快照先返回时先显示其明确的历史日期，行情到达后更新为最新记录；行情失联时继续显示快照且标明快照来源。Sites 还提供固定地址的同源快照代理，减少国内访客浏览器直接访问 GitHub Pages 的依赖。
- 日线原始金额为万元，统一换算为亿元计算；大额在页面转换为万亿元，CSV 统一保留亿元。这里只统计**成交额**，不是股数或基金份数。仅对两市都有数据的交易日计算合计，休市日不补值。20 日平均＝累计 ÷ 20；资金温度＝当日沪深合计 ÷ 20 日平均。
- 科创板按上交所股票成交概况的科创板栏目取成交金额（亿元）；沪深 ETF 逐批检索腾讯行情沪市以 `0` 结尾的 5 开头代码，以及深市 158/159 全代码段，只累计报价分类为 `ETF` 且时间戳为同一交易日的证券，并检测每批是否完整返回。2026-09-24 的沪市部分再与上交所公布的沪市 ETF 成交额核对。盘中固定这一统计范围；抓取失败时不以覆盖数量不同的接口替换，以免累计额发生假性下跌。510300 使用腾讯财经对应 ETF 日线。细分项属于上层市场，不能跨层相加。
- GitHub Actions 在北京时间工作日 12:13 和收盘后多个错峰时点获取细分项；晚间补采优先复用已核验的收盘 ETF 结果，并独立回填此前缺失的科创板分类记录，核验后写入 `public/data/market-snapshot.json` 并部署页面；快照也记录两市行情时间。开盘前及休市日若两市收盘额未变化，采集器停止后续 ETF 全代码扫描，也不改写快照核验时间。同日收盘后对日线与即时报价核对，并要求沪、深两个报价日期与目标交易日一致。CI 在提交和发布前核对交易日顺序、金额正值、ETF 沪深分项之和、510300 包含关系、历史补录出处，以及滚动 20 日基准。2026-09-14 至 09-23 的 ETF 历史趋势由 `data/etf-archive.json` 补录财闻逐日 ETF 日报数据，每条含原文 URL，采集器只填补缺失历史值、不覆盖实时全代码段记录；后续 ETF 历史从采集成功之日积累。两种来源在页面和 CSV 明确区分。页面打开、重新显示及多个收盘后定点时刻读取腾讯行情；工作日 09:15—16:30 页面可见时每 2 分钟核对一次，夜间及周末不重复轮询。盘中成交额标记为暂计，日变化、温度和完整滚动值等到收盘核实后展示，CSV 也区分数据阶段。历史 510300 优先复用已核实快照，只有当日交易或快照缺失时读取该 ETF 完整日线。抓取、阈值和图表使用确定性代码计算，不调用大模型接口。细分项缺失或日期不符时显示待核实。
- 这里是指数行情提供的沪深市场成交额口径，与交易所股票分类统计可能有细微差异。2026-09-24 的深证成指行情额约 8697.44 亿元，而深交所官网当日股票成交额为 8708.85 亿元；两种口径不混入同一滚动序列。科创综指只覆盖符合条件的成份证券，不直接替代科创板官方全部股票成交额。ETF 不依赖固定的历史代码名单，以免漏掉新增产品。页面的区间和文字为观察参考，不是可验证的买卖信号。腾讯接口并非本站控制，访问限制或源字段变化时展示最近核验快照。定时刷新在页面打开时运行；休市日保留最近交易日，并显示数据日期。

## GitHub Pages 发布

`collect-market.yml` 在工作日北京时间 12:13、15:27、15:53、16:19、16:47、17:17、17:43、18:31、采集器代码变更或手动触发时采集；校验成功且快照发生变化才提交历史记录，并显式调用 `pages.yml` 发布新数据。`pages.yml` 在代码推送时只校验已提交快照并构建页面，不抓取行情；采集工作流的 `GITHUB_TOKEN` 提交不会自动触发推送工作流，所以数据更新时由采集工作流直接调用发布工作流。科创板优先采用上交所分类成交，若接口不可用，则用东方财富与腾讯逐股报价的完整覆盖、日期和金额校验后的汇总结果；两源均可用时核对数量和金额差，记录实际来源，核对失败时继续显示待核实。仓库的 Pages 来源已设为 GitHub Actions。页面在交易可变时段保持打开会定时读取行情，重新打开时立即抓取。GitHub Pages 在不同地区的连通性取决于当地网络，部署成功不代表中国大陆各运营商均稳定可达。

观点库保存在 `lib/investorQuotes.ts`，包含原有段永平、查理·芒格、巴菲特以及霍华德·马克斯、特里·史密斯等，共 301 条。新增资料包括伯克希尔 2020—2024 年致股东信和橡树资本公开备忘录。每条都附原始资料、具体页码或章节和链接；中文短句依据原文归纳或意译，不是逐字引述。观点库 CSV 下载位于页面最底部。手机分享卡片采用紧凑布局，可在一屏显示观点、出处、五项市场数据和操作按钮，保存的 PNG 始终绘制全部内容。

引用文字使用站内自托管的霞鹜文楷字体，图片导出等待字体加载；字形由 Fontsource 的 LXGW WenKai 5.3.0 字库按当前观点库精简，许可证见 `public/fonts/OFL-LXGW-WenKai.txt`。观点库增加新字时须重新生成字体子集。

## 漏采恢复

GitHub Actions 的 `schedule` 可能延迟或不触发。网页在完整收盘行情已确认、当日科创板或 ETF 快照缺失时，直接通过腾讯逐只报价脚本遍历科创板 688/689 及沪深 ETF 全代码段，按日期、代码、金额双字段、完整覆盖数量与沪深分项核验；只有通过校验的数值才显示，且明确标记“浏览器补采”。浏览器的科创板逐只报价为竞价口径参考值，可能与包含其他交易方式的上交所分类终值略有差异；官方快照恢复后优先使用交易所分类结果。已补采结果缓存于当前浏览器，快照恢复后以仓库核验数据为准。若行情接口不可达，保留“待核实”并延时重试。仓库采集器也会继续补齐前一交易日缺失的科创板或 ETF 数据。`?checkDetail=1` 可在已核验日期执行一次逐只重算并比较快照，作为不修改数据的现场诊断。浏览器临时补采不替代仓库历史归档，若 GitHub 调度持续失效，跨日 ETF 历史仍需独立调度服务。

## 独立定时器（Cloudflare 免费方案，待账号部署）

`scheduler/worker.mjs` 使用 Cloudflare Cron Trigger 作为 GitHub `schedule` 之外的时钟；原有 `workflow_dispatch` 工作流仍负责采集、校验、提交与发布。定时器北京时间工作日 12:41、15:41、16:11、16:41、17:11、17:41、18:11、18:41 检查仓库快照；午间已更新或收盘后两市报价、上交所科创板分类成交、ETF 全代码段及分市场核对均完成时跳过，否则触发工作流。请求被 GitHub 接受不等于采集成功，下一个时点会再检查快照并重试。休市工作日可能触发空跑，采集器会根据行情日期退出。密钥只存 Cloudflare Secret，不提交到仓库；凭证失效或服务故障需查看 Cloudflare 运行日志并轮换。

部署需仓库所有者完成以下账号操作（不要把令牌发在聊天中）：

1. 注册或登录 Cloudflare 免费账号；在 GitHub `Settings → Developer settings → Personal access tokens → Fine-grained tokens` 创建仅授权 `GitYx4029/Polaris-and-Compass` 的令牌，仓库权限 `Actions: Read and write`，记录到期时间。
2. 在仓库根目录执行 `npx wrangler login`，然后执行 `npx wrangler secret put GITHUB_ACTIONS_TOKEN --config scheduler/wrangler.jsonc`，在本机提示符输入令牌；再执行 `npx wrangler deploy --config scheduler/wrangler.jsonc`。令牌不要写入命令、文件或公开日志。
3. 在 Cloudflare Workers 的 `polaris-market-watchdog → Triggers` 确认三条 UTC Cron；在 `Logs` 查看第一次定时运行结果 `verified` 或 `dispatched`。当工作流被触发时，到 GitHub Actions 确认 `Collect verified market snapshot` 成功，并在页面核对数据日期。密钥到期前需在 GitHub 轮换并重新执行 `wrangler secret put`。

本地无需行情 API 的检查：`node scheduler/self-check.mjs`。定时器只负责触发 GitHub 工作流，若 GitHub Actions 本身整日不可用，历史归档仍无法完成。
