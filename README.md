# Polaris and Compass · A股成交观察

[在线使用](https://a-share-pulse-lxy-0924.reagan-park-6434.chatgpt.site/)

展示沪深两市单日成交额、近 20 个交易日滚动累计和交易日明细，支持下载历史 CSV。页面打开时，周一至周五北京时间 12:00、15:15 定点刷新，平时每 2 分钟更新，页面重新显示也会读取；行情读取失败时显示错误，不填入虚构数值。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。运行 `npm run build` 检查生产构建。

## 数据与单位

- 数据来自腾讯行情上证指数 `sh000001`、深证成指 `sz399001` 的日线成交额，并用同一接口的即时报价字段核对近期日期及金额。服务端优先获取；遇到服务端网络不可达时，浏览器会尝试直连。
- 日线原始金额为万元，展示的沪市、深市、合计及近 20 日累计为万亿元；CSV 同时提供亿元原值与万亿元的滚动累计。只对两市都有数据的交易日计算合计，休市日不补值。
- 这里是指数行情提供的沪深市场成交额口径，与交易所严格仅计 A 股的分类统计可能有细微差异。页面的区间和文字为观察参考，不是可验证的买卖信号。腾讯接口并非本站控制，访问限制或源字段变化可能造成暂时不可用。定时刷新在页面打开时运行；休市日保留最近交易日，并显示数据日期。
