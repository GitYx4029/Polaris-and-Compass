# Polaris and Compass · 大A观测助手

[在线使用（GitHub Pages）](https://gityx4029.github.io/Polaris-and-Compass/)

展示上证、深证、沪深合计、科创板、沪深 ETF 和 510300 沪深300ETF华泰柏瑞成交额，以及近 20 交易日累计、日均与资金温度。两张趋势图均可用横向日期滑轨精确选择交易日；各数值与表格列均有单项历史 CSV 下载，另有完整历史 CSV。手机上的近期交易日改为可展开卡片，可下载当日数据；三块解读参考在手机上左右滑动。Reference list 依次呈现指南针（日成交额）、北极星（20 日累计）、资金温度计及指标层级，并注明观察工具箱来自“袁莹投资思维”；这些观察阈值并非经验证的交易信号。页面打开时北京时间 12:00、15:15 定点刷新；每日轮换一条有出处的投资观点，可保存包含五项行情及数据阶段的 PNG 图片、复制含出处的文案或调用系统分享，也可导出观点库。

## 本地运行

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开 http://localhost:3000 。运行 `npm run build` 检查生产构建。

## 数据与单位

- 数据来自腾讯行情上证指数 `sh000001`、深证成指 `sz399001` 的日线成交额，并用同一接口的即时报价字段核对近期日期及金额。GitHub Pages 静态版直接从浏览器读取腾讯行情脚本接口；Sites 版本先走服务端，失败时由浏览器直连。已核验快照与行情并行获取：快照先返回时先显示其明确的历史日期，行情到达后更新为最新记录；行情失联时继续显示快照且标明快照来源。Sites 还提供固定地址的同源快照代理，减少国内访客浏览器直接访问 GitHub Pages 的依赖。
- 日线原始金额为万元，统一换算为亿元计算；大额在页面转换为万亿元，CSV 统一保留亿元。这里只统计**成交额**，不是股数或基金份数。仅对两市都有数据的交易日计算合计，休市日不补值。20 日平均＝累计 ÷ 20；资金温度＝当日沪深合计 ÷ 20 日平均。
- 科创板按上交所股票成交概况的科创板栏目取成交金额（亿元）；沪深 ETF 首选东方财富 ETF 行情的全部分页（`f6` 成交额，元），检查总记录数、代码去重及同日时间戳再求和。东方财富不可用时，逐批检索腾讯行情沪市以 `0` 结尾的 5 开头代码，以及深市 158/159 全代码段，只累计报价分类为 `ETF` 且时间戳为同一交易日的证券，并检测每批是否完整返回。2026-09-24 的沪市部分再与上交所公布的沪市 ETF 成交额核对。510300 使用腾讯财经对应 ETF 日线。细分项属于上层市场，不能跨层相加。
- GitHub Actions 在北京时间工作日 12:10 和 15:25 获取细分项，核验后写入 `public/data/market-snapshot.json` 并部署页面；快照也记录两市行情时间。开盘前及休市日若两市收盘额未变化，采集器停止后续 ETF 全代码扫描，也不改写快照核验时间。同日收盘后对日线与即时报价核对，并要求沪、深两个报价日期与目标交易日一致。CI 在提交和发布前核对交易日顺序、金额正值、ETF 沪深分项之和、510300 包含关系、历史补录出处，以及滚动 20 日基准。2026-09-14 至 09-23 的 ETF 历史趋势由 `data/etf-archive.json` 补录财闻逐日 ETF 日报数据，每条含原文 URL，采集器只填补缺失历史值、不覆盖实时全代码段记录；后续 ETF 历史从采集成功之日积累。两种来源在页面和 CSV 明确区分。页面打开、重新显示、12:00 和 15:15 时读取腾讯行情；工作日 09:15—16:30 页面可见时每 2 分钟核对一次，夜间及周末不重复轮询。盘中成交额标记为暂计，日变化、温度和完整滚动值等到收盘核实后展示，CSV 也区分数据阶段。历史 510300 优先复用已核实快照，只有当日交易或快照缺失时读取该 ETF 完整日线。抓取、阈值和图表使用确定性代码计算，不调用大模型接口。细分项缺失或日期不符时显示待核实。
- 这里是指数行情提供的沪深市场成交额口径，与交易所股票分类统计可能有细微差异。2026-09-24 的深证成指行情额约 8697.44 亿元，而深交所官网当日股票成交额为 8708.85 亿元；两种口径不混入同一滚动序列。科创综指只覆盖符合条件的成份证券，不直接替代科创板官方全部股票成交额。ETF 不依赖固定的历史代码名单，以免漏掉新增产品。页面的区间和文字为观察参考，不是可验证的买卖信号。腾讯接口并非本站控制，访问限制或源字段变化时展示最近核验快照。定时刷新在页面打开时运行；休市日保留最近交易日，并显示数据日期。

2026-09-24 收盘核对样例：沪市 7836.1300 亿元、深市 8697.4436 亿元，合计 16533.5736 亿元，即 1.65335736 万亿元，页面显示 1.65 万亿。ETF 汇总 4786.4599 亿元，其中沪市 3777.4535 亿元、深市 1009.0064 亿元；上交所公布的沪市 ETF 成交额为 3777.45 亿元，四舍五入后吻合。2026-09-25 休市时最近交易日仍为 2026-09-24。

## GitHub Pages 发布

`main` 分支包含 GitHub Actions 工作流，抓取数据并执行 `npm run build` 后将 `out/` 发布到 Pages；仓库的 Pages 来源已设为 GitHub Actions。页面在交易可变时段保持打开会定时读取行情，重新打开时立即抓取。GitHub Pages 在不同地区的连通性取决于当地网络，部署成功不代表中国大陆各运营商均稳定可达。

观点库保存在 `lib/investorQuotes.ts`，包含原有段永平、查理·芒格、巴菲特以及新增的霍华德·马克斯、特里·史密斯等，共 120 条。每条都附原始资料、具体位置和链接；页面的中文短句是依据原文归纳或意译，不是逐字引述。可导出 CSV 审核每条来源。
